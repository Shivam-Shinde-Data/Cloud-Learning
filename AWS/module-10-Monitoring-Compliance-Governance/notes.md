# Module 10: Monitoring, Compliance, and Governance in the AWS Cloud 📊☁️

---

## 📌 What is Monitoring, Compliance, and Governance?

Monitoring helps track the performance and health of cloud resources.  

Compliance ensures that systems follow legal, security, and business standards.  

Governance helps organizations manage resources properly by applying rules, policies, and controls.

These three areas are important for maintaining secure, reliable, and well-managed cloud environments.

---

## 📈 Amazon CloudWatch

Amazon CloudWatch is a monitoring service used to track the performance and health of AWS resources and applications.  

It collects metrics, logs, and events to help identify issues and improve system performance.

📌 Example: Monitoring CPU usage of an EC2 instance

---

## 📜 AWS CloudTrail

AWS CloudTrail records user activity and API calls across AWS services.  

It helps organizations audit actions, investigate security events, and maintain compliance.

📌 Example: Checking who created or deleted a resource

---

## 🛡️ AWS Config

AWS Config is a service that tracks resource configurations and records changes over time.  

It helps ensure that resources remain compliant with organizational policies.

📌 Example: Detecting if a security group was changed incorrectly

---

## 🧭 AWS Organizations

AWS Organizations helps manage multiple AWS accounts centrally.  

It allows businesses to apply policies, billing controls, and security rules across all accounts from one place.

This is useful for large organizations with multiple teams or departments.

---

## 🔒 Service Control Policies (SCPs)

Service Control Policies are rules used within AWS Organizations to control permissions across multiple AWS accounts.  

They define the maximum permissions allowed for users and accounts.

This improves governance and prevents accidental misuse of resources.

---

## 📋 AWS Trusted Advisor

AWS Trusted Advisor provides recommendations for improving cost optimization, security, fault tolerance, performance, and service limits.  

It helps users follow AWS best practices.

📌 Example: Finding unused resources that increase cost

---

## 🏛️ Compliance in AWS

AWS supports compliance with industry standards such as ISO, SOC, GDPR, and HIPAA.  

It provides tools and documentation to help businesses meet regulatory requirements.

This is important for industries like banking, healthcare, and government.

---

## 🔁 Governance Best Practices

Good governance includes:

- Monitoring resources regularly  
- Applying least privilege access  
- Managing costs efficiently  
- Enforcing security policies  
- Tracking configuration changes  

These practices improve operational control and reduce risks.

---

## 🧠 Key Takeaways

CloudWatch is used for monitoring performance and health of resources.  

CloudTrail records user activity for auditing and security purposes.  

AWS Config helps maintain compliance by tracking configuration changes.  

AWS Organizations and SCPs improve governance across multiple accounts.

## 🎯 Interview Questions

### Q1. What is Amazon CloudWatch?  
Amazon CloudWatch is a monitoring service used to track metrics, logs, and events for AWS resources and applications.

---

### Q2. What is the difference between CloudWatch and CloudTrail?  
CloudWatch monitors performance and health, while CloudTrail records user activity and API calls for auditing.

---

### Q3. What is AWS Config?  
AWS Config is a service that records resource configurations and helps ensure compliance with policies.

---

### Q4. What is AWS Organizations?  
AWS Organizations is a service used to centrally manage multiple AWS accounts with shared policies and billing controls.

---

### Q5. What are Service Control Policies (SCPs)?  
SCPs are policies that define the maximum permissions allowed across AWS accounts in an organization.
